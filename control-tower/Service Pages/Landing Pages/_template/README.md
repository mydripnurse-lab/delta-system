# Landing Page Template Contract

Required inputs before generating a service landing page:

- Canonical Admin service record and current price.
- Primary keyword and `{{custom_values.county_name_and_state}}` placement plan.
- Matching CTA survey path from the official Google Sheet.
- Approved service images, alt text and image title.
- Approved benefits, ingredients and medical disclaimer.
- Competitor/research brief using reliable primary sources.

Required output:

- Embedded body only: no header, footer, canonical, robots, title or meta description.
- Mobile-first layout and accessible CTA states.
- On-page SEO copy with one clear H1 and a useful heading hierarchy.
- Localized FAQ content and valid JSON-LD schemas supported by visible page content.
- Dynamic coverage section based on the supplied location-navigation component.
- Bonjoro testimonial embed.
- Every booking CTA points to the exact survey page for the service.
