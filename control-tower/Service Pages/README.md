# My Drip Nurse Service Pages

This directory is the production workspace for the three-page service flow hosted in GHL:

1. `Landing Pages`: indexable service content and CTA to the matching GHL survey page.
2. `Survey`: the exact GHL survey embed supplied for that service.
3. `Calendars`: the My Drip Nurse calendar embed for the same canonical service.

Service price, deposit, image, ingredients, benefits and calendar identity come from `admin.mydripnurse.com`. GHL remains responsible for the page shell, domain, title, meta description, canonical and robots settings.

Each service receives the same slug inside all three directories. Do not create a Survey template for a service until the exact GHL embed has been supplied and confirmed.
